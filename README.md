# Готель для котів і собак «Лапка»

Навчальний сайт готелю для тварин у Львові. Проєкт продовжує ЛР № 7 та підготовлений до публікації на GitHub Pages і Netlify в межах ЛР № 8.

## Можливості

- Адаптивна головна сторінка та мобільне меню.
- Сторінки послуг, умов проживання та відгуків.
- Калькулятор вартості з вибором тварини, тарифу й додаткових послуг.
- Навчальна форма з перевіркою даних у браузері.
- YouTube-відео, Google Maps та погодний інформер Open-Meteo.

Форма не надсилає заявку адміністратору та не створює реального бронювання.

## Технології

HTML5, JavaScript, локальна збірка Tailwind CSS, додатковий CSS, локальні шрифти Roboto та PT Serif. npm і окрема команда збірки не потрібні. Для відео, карти та погоди потрібен Інтернет.

## Запуск

Відкрити папку у Visual Studio Code, потім `index.html` через **Open with Live Server**. Альтернатива з кореня проєкту:

```sh
python -m http.server 5500
```

Адреса: `http://localhost:5500/`.

## Структура

- `index.html` — головна сторінка.
- `services.html`, `service-cats.html`, `service-dogs.html` — послуги.
- `conditions.html`, `reviews.html` — умови й відгуки.
- `calculator.html`, `application.html` — калькулятор і форма.
- `assets/` — стилі, JavaScript, зображення, іконки, шрифти та ліцензії.
- `netlify.toml` — публікація кореневої папки без збірки.
- `.nojekyll` — статичні файли без обробки Jekyll на GitHub Pages.
- `DEPLOYMENT.md` — покрокова публікація та перелік скріншотів.

## Публікація

Публічний репозиторій: <https://github.com/nazar-tsventarnyi/hotel-lapka>.

Наявна адреса Netlify з ЛР № 7: <https://hotel-lapka.netlify.app/>.

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.


**Netlify:** підключити GitHub-репозиторій, обрати `main`, залишити Build command порожнім; Publish directory — `.`. Це значення задано й у `netlify.toml`.

Після підключення платформ push у `main` запускає оновлення сайту. Локальні шляхи відносні, тому сайт працює і в підкаталозі GitHub Pages.
