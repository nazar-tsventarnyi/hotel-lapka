# Промпт паспорт ЛР 8

## Запит

«реалізуй мені цю лабу кинув також зразок готової, якщо потрібно якісь фотки скажи які потрібно зробити».

Додаткові дані: основа — актуальна локальна папка «Лапка» з ЛР № 7. Для роботи використано публічний репозиторій `nazar-tsventarnyi/hotel-lapka`.

## Рішення

Збережено HTML, CSS, JavaScript і ресурси. Створено локальний Git-репозиторій. Окремі коміти містять основу сайту, налаштування публікації та документацію. Додано `.gitignore`, `.gitattributes`, `.nojekyll`, `netlify.toml`, README й інструкцію публікації. Документацію внесено у гілці `docs/deployment` та злито в `main`.

## Аналіз

Відносні шляхи дають змогу розміщувати сайт у підкаталозі GitHub Pages. Netlify не потребує збірки для статичних файлів. Поділ змін на змістовні коміти робить історію зрозумілою. Публікацію та синхронізацію підтверджують після виконання в облікових записах користувача.
